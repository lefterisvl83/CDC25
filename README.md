# CDC25
This repository contains MATLAB scripts used for producing the example section of the paper entitled "Conformal Data-driven Control of Stochastic Multi-Agent Systems
under Collaborative Signal Temporal Logic Specifications" submitted for presentation at the IEEE 2025 Conference on Decision and Control (CDC). The paper is available online here: https://arxiv.org/abs/2504.04615.
The scripts require the MPT3 toolbox, YALMIP, and the GUROBI and MOSEK solvers.
